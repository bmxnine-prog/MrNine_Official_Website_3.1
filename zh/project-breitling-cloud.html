精選作品・10

Breitling Cloud

雲朵紋飾雕刻・錶殼與錶帶

作品構想

雲朵紋飾在 Breitling 經典線條上流動融合。

Breitling Cloud 以雲形紋飾銜接錶殼與錶帶，保留腕錶厚實輪廓，同時提升表面細節的雕刻層次。精準手工刻面讓紋飾在整體構圖中呈現節奏與深度。
