Breitling Cloud

Engraved cloud motif · Case and bracelet

The project

Cloud-inspired engraving crafted for a bold Breitling presence.

The Breitling Cloud project uses flowing cloud forms to bridge the case and bracelet, maintaining the watch’s strong profile while adding ornate surface detail. Precision hand-cut relief gives the pattern depth and rhythm across the entire design.
